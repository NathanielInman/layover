Fixtures for layover-core's parsers. Recorded from the desk unless noted;
window titles, songs, meeting names, secret names and task text are replaced
with "(… removed)".

- `hyprland-clients.json`: `hyprctl -j clients`, plus an mpv and a T3 Code
  window holding idle inhibitors.
- `pactl-*.json`: `pactl -f json list sink-inputs` and `source-outputs`.
- `lamps/`: one lamp line from each tool's `bar` stream. `*-live`, `-off`,
  `-act-hot`, `-held`, `-paused`, `-free`, `-needs-you` and `-idle` were
  recorded; the rest follow each tool's documented bar output.
